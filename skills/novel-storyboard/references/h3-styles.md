# H3 八种风格预设

来源：MiniMax-H3 官方仓库 `skills/` 目录（快照 commit `d21241f0a4b3acbb34c97dae47fa417b7065e438`，2026-08-28 核对）。这里把 `h3-prompt-writing` 之外的 8 个技能拆成 **H3 提示词风格层**：只继承会改变生成结果的视觉、运动、转场、文字与声音语法，不继承 Hub 工具、用户确认流程、固定时长、品牌业务规则或交付步骤。

## 怎么选

```bash
node scripts/novel-storyboard.mjs h3-styles
node scripts/novel-storyboard.mjs h3-styles paper-collage-explainer-generator --lang en
node scripts/novel-storyboard.mjs seed script.json --h3-style paper-collage-explainer-generator
```

顶层 `h3Style` 可省略；省略就是官方基础写法，不强套类型风格。选了以后，先用 `h3-styles <id> --lang <promptLang>` 取得确定性风格指纹，逐字放进每段视听描述的 `[Shot 1]`。`style-phrase` 门会逐段检查。

`style` 与 `h3Style` 不是同一个开关：

- `style` 管静态分镜图及上游角色/场景资产的画风。
- `h3Style` 管视频阶段的运动、剪辑、文字包装和声音手感。
- 纸艺、拼贴、3D、手绘实拍这类强材质风格必须同时准备相符的分镜图/角色/场景参考；H3 不会可靠地把真人首帧凭文字变成纸艺或 3D。

## 8 个 id

| `h3Style` | 中文名 | 适合 | 不要机械继承 |
| --- | --- | --- | --- |
| `minimalist-product-ad-generator` | 极简产品广告 | 道具/产品主导、材质特写、功能揭示、克制高级感 | Apple 仿牌、固定广告文案、每镜强塞文字 |
| `3d-animation-short-generator` | 风格化 3D 动画 | 角色动画、喜剧、童话、弹性表演 | 固定头身比、固定角色设计、Hub 制作流程 |
| `papercraft-stop-motion-explainer` | 纸艺定格 | 分层科普、机关、立体书、微缩舞台 | 固定讲解员、固定 30 秒、每镜强塞标签 |
| `brand-promo-video-generator` | 品牌宣传 | 产品能力、界面证据、品牌动作、CTA 收束 | 未核验主张、伪造 Logo、固定品牌故事结构 |
| `music-video-subtitle-generator` | 音乐美学贴字 | MV、歌词事件、卡拍硬切、表演型片段 | 没有音乐时硬套 MV、把文字当普通字幕条 |
| `co-op-game-intro-generator` | 双人游戏菜单 | 双角色菜单、游戏 UI、Continue 交互 | 固定人物坐姿、固定玩家名、完整可玩 UI |
| `paper-collage-explainer-generator` | 半调纸拼贴 | 编辑感 B-roll、抽象隐喻、触感组装 | 自动加旁白/BGM/字幕、平滑数字图层运动 |
| `handdrawn-live-video-generator` | 手绘实拍融合 | 日常空间中的手绘实体、接触、连续变形 | 固定 15 秒剧情模板、恐怖编码、突然换实体 |

## 风格语法

### 极简产品广告

- 视觉：干净留白、真实产品颜色与材质、轮廓/结构/高光主导，避免镜面白底和伪科技装饰。
- 运动：每拍一个主动作；开合、旋转、吸附、滑入、材质高光等真实结构动作。
- 转场：产品边缘、匹配几何、颜色和高光驱动，不用随机闪白或粒子。
- 文字：有需要时只保留稀疏、单行、短文案；它是构图元素，不是下方字幕。
- 声音：精确产品 Foley 与克制音乐同步，避免堆叠轰鸣。

### 风格化 3D 动画

- 视觉：高品质风格化 3D、强剪影、可触材质、温润 SSS；拒绝真人写实与塑料玩具皮肤。
- 表演：anticipation → action → overshoot → settle，使用 squash-and-stretch、follow-through 和可读微表情。
- 镜头：动作快但姿态要读得清；荷兰角只服务追逐、失衡或惊吓。
- 连续性：人物位置、道具、地标和光位跨 Shot 继承。
- 声音：动作重音与弹性表演同步，不用无因果的卡通音效墙。

### 纸艺定格

- 视觉：4–7 层微缩纸雕布景，可见卡纸厚度、纤维、折痕、剪裁边和真实层间投影。
- 运动：逐帧小位移、短暂停顿、轻微回弹、铰链、滑轨、拉片、转盘和纸片落定。
- 镜头：微距摄影、轻景深、缓推/横移/轻俯视和 2.5D 视差。
- 转场：翻页、立体书展开、纸牌遮挡、纸门开启、抽拉机关。
- 声音：翻纸、滑轨、卡扣、摩擦、胶带等轻触感 Foley；音乐服从题材并给对白留白。

### 品牌宣传

- 视觉：产品、界面、主张与资产证据必须可读；抽象效果只能做辅助层。
- 运动：每拍一个主动作，用产品运动、滚动、光标、光线、边缘或匹配几何带出下一拍。
- 节奏：高能峰值与安静制动交替，最终保留 Logo/文案/CTA 安全区。
- 文字：只使用已确认文案；不虚构数据、功能、标识。
- 声音：优先统一原生声场；对白、音乐、UI 音各守自己的层，不重复生成同一声轨。

### 音乐美学贴字

- 视觉：胶片颗粒、半调、zine/扫描错位可按项目选用，但整段保持同一美学头。
- 剪辑：切点落在鼓点、呼吸或句间停顿；默认硬切、动作匹配切或同向动势承接。
- 文字：歌词是空间图层，每 Shot 一个主文字事件；逐字匹配演唱，不遮眼睛和嘴。
- 表演：嘴型、下颌、呼吸、点头和手势跟随 phrasing 与 groove。
- 声音：整支片绑定同一 Master Audio；`non_diegetic_music` 不另造一条冲突曲目。

### 双人游戏菜单

- 视觉：两名身份锁定角色与主机菜单 UI 深度融合；高对比但不超过约五种主色。
- 布局：UI 不遮角色；标题与按钮单行，层级清楚，图标一排且数量克制。
- 运动：按进入 → 玩家卡 Ready → Continue 高亮/点击 → 响应收束的事件链执行。
- 文字：只保留剧本/项目提供的菜单文案，模型文字不稳时减少而不是堆叠。
- 声音：菜单 hover、Ready、Continue 点击与界面响应一一对齐。

### 半调纸拼贴

- 视觉：大色块、黑白半调剪影、选择性彩色卡纸、暖白描边、纤维撕边、纸缝和软纸影。
- 运动：纸片按可读顺序弹入/滑入 → 轻回弹 → 压平 → 暂停 → 锁定。
- 镜头：默认稳定，不加无意义缩放或漂浮；构图有前中后景但保持留白。
- 转场：由纸片遮挡、替换和组装完成，不用平滑数字变形。
- 声音：默认触感拼贴 Foley；除非剧本已有，不额外发明 BGM、旁白或字幕。

### 手绘实拍融合

- 视觉：真实日常空间 + 粗糙发光蜡笔/粉笔/彩铅/粉彩线条，带抖动、毛边和逐帧重画感。
- 运动：手绘实体先与真实手/物清楚接触，再作为同一实体连续变形；每种形态保留前态的线、色或拖痕。
- 镜头：手持相机慢半拍追随，不把实体稳定居中；尽量在同一或相邻空间连续展开。
- 调性：生活感、可爱、温柔，允许小恶作剧；拒绝威吓、牙齿、扑咬、跳吓和恐怖变形。
- 声音：保留真实 room tone、接触声和拍摄者反应，手绘实体的音效轻而具体。

## 冲突处理

1. 剧本事实、角色/场景/道具参考和 `sourceState` 优先于风格。
2. 官方 H3 字段、Picture 标签、Shot 时刻、`<d>` 台词与 `(Sx)` 优先于风格措辞。
3. `cameraPlan` 已指定主运镜时，风格只能调整速度、质感与剪辑手感，不能再塞第二个冲突运镜。
4. 风格默认不新增剧情、对白、Logo、歌词、字幕、产品功能或 UI 文案。
5. 风格与参考图材质冲突时先修参考资产，不靠长负面词硬扭视频模型。
